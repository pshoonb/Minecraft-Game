RPG Core Prototype 0.3.0

Target:
- Minecraft Java Edition 1.21.1
- NeoForge 21.1.265
- Java 21

Implemented:
- RPG level mirrors the vanilla player experience level.
- Attribute points are based on the highest vanilla level ever reached, so spending vanilla levels does not revoke earned points.
- Exactly seven assignable attributes: Strength, Health, Defense, Mining Speed, Luck, Speed, and Jump Height.
- Agreed cumulative attribute-point formula remains unchanged.
- Free attribute reset.
- Server-authoritative attribute allocation and reset.
- Per-player attachment persistence and UUID-checked client sync.
- P-key attribute screen with English and Simplified Chinese localization.
- Removed diagnostic counter UI/network payload and separate RPG XP progression.
- First-pass gameplay effects for all seven attributes.
- Gameplay events are registered explicitly by the mod entry point.
- Server refreshes the player's transient attribute modifiers every 20 ticks from saved RPG data.
- Jump Height modifies the upward velocity of actual player jumps.

Updated prototype tuning values (subject to playtesting):
- Strength: +0.50 attack damage per square-root attribute point.
- Health: +1.00 maximum health per square-root attribute point.
- Defense: +0.50 armor per square-root attribute point.
- Mining Speed: +1% block-break speed per square-root attribute point.
- Luck: +0.10 vanilla luck per square-root attribute point.
- Speed: +0.5% movement speed per square-root attribute point.
- Jump Height: +1% upward jump velocity per square-root attribute point.
- Each attribute's effect input is capped at 10,000 points and uses square-root scaling.
- Current RPG level does not grant separate automatic health or armor bonuses; level progression awards attribute points according to the agreed formula.

Legacy data upgrade:
- Previously allocated Strength points are retained.
- Allocations in the removed prototype attributes (Agility, Constitution, Intelligence, Spirit) are refunded to the available point pool.
- Current level, highest reached level, and the earned-point formula are retained.

Not implemented:
- Final balancing of the seven first-pass values.
- Exploration, quests, gathering-specific rewards, monster scaling, equipment, or loot systems.
- Full multiplayer and compatibility testing with other attribute-modifying mods.

Validation required:
- GitHub Actions build and in-game testing for this revision.
- Verify all seven attribute effects, reset, level spending, login/respawn persistence, and multiplayer isolation.
