# RPG Core Prototype 0.3.0

Minecraft Java 1.21.1 / NeoForge 21.1.265 / Java 21。

RPG Core 保留原版生存、建造、挖矿、合成与经验系统；当前不设置职业、技能树或职业限制。

## 当前成长系统

- RPG 等级直接跟随 Minecraft 原版玩家经验等级。
- 属性点按玩家达到过的最高等级累计计算。消耗原版等级不会追回已经获得的属性点。
- 每次达到等级 x 的属性点奖励为 floor(x / 2) + min(100, x)。
- 累计属性点公式保持不变：P(x) = floor(x² / 4) + x(x + 1) / 2（0 到 100 级）；P(x) = floor(x² / 4) + 100x - 4950（100 级以上）。
- 玩家可自由分配七项属性：力量、生命值、防御力、挖掘速度、幸运、速度、跳跃高度。
- 玩家数据由服务器验证、按玩家独立保存，并同步给对应玩家；免费重置保留。

## 属性点软上限

属性效果使用以下曲线：

\[
E(p)=
\begin{cases}
p,&p\le25\\
25+15\ln(1+(p-25)/15),&p>25
\end{cases}
\]

前 25 个有效属性点按完整比例生效；之后逐渐降低每个新增点的边际收益，但不会在某个点数停止成长。

## 七项属性的新版数值

| 属性 | 每个有效属性点的效果 |
|---|---:|
| 力量 | +0.10 攻击伤害 |
| 生命值 | +0.25 最大生命值 |
| 防御力 | +0.15 护甲；另有最终伤害减免、燃烧时间缩短和爆炸击退减弱 |
| 挖掘速度 | +1% 方块破坏速度，另加 +0.15 挖掘效率 |
| 幸运 | +0.10 原版 Luck |
| 速度 | +0.5% 移动速度 |
| 跳跃高度 | +0.5% 起跳向上速度 |

防御力的额外效果：
- 最终伤害减免：最高逐渐趋近 40%，在原版护甲和附魔处理后计算，因此也覆盖绕过护甲的伤害类型。
- 燃烧持续时间缩短：最高逐渐趋近 60%。
- 爆炸击退抵抗：最高逐渐趋近 70%。
- 护甲属性加成本身最多 +20；达到该值后，最终伤害减免、燃烧和爆炸保护仍继续成长。

## 按实际可达到等级评估

本项目将 100–150 级作为主要平衡区间，而不是按极少数玩家可能达到的 1000 级设计。

| 原版等级 | 累计属性点 | 平均分配到七项时，每项原始点数 | 每项有效点数约 |
|---:|---:|---:|---:|
| 10 | 80 | 11.4 | 11.4 |
| 100 | 7,550 | 1,078.6 | 89.0 |
| 150 | 15,675 | 2,239.3 | 100.0 |

例子：
- 投入 10 点力量：+1 攻击伤害。
- 投入 10 点生命值：+2.5 最大生命值。
- 投入 10 点防御力：+1.5 护甲、约 6.7% 额外最终伤害减免、约 15% 燃烧时间缩短、约 14% 爆炸击退抵抗。
- 投入 10 点挖掘速度：+10% 方块破坏速度、+1.5 挖掘效率。
- 投入 10 点幸运：+1 Luck。
- 投入 10 点速度：+5% 移动速度。
- 投入 10 点跳跃高度：+5% 起跳速度（理论上约增加 10% 跳跃高度）。

若在 100 级时将 7,550 点平均分配到七项：
- 力量约 +8.9 攻击伤害；生命值约 +22.2 最大生命值。
- 防御力约 +13.3 护甲，并额外减少约 25.6% 最终伤害。
- 挖掘速度约 +89% 方块破坏速度，并增加约 13.3 挖掘效率。
- 幸运约 +8.9 Luck；速度约 +44.5%；跳跃起跳速度约 +44.5%。

若在 150 级时平均分配 15,675 点：
- 力量约 +10 攻击伤害；生命值约 +25 最大生命值。
- 防御力约 +15 护甲，并额外减少约 26.7% 最终伤害。
- 挖掘速度约 +100% 方块破坏速度，并增加约 15 挖掘效率。
- 幸运约 +10 Luck；速度约 +50%；跳跃起跳速度约 +50%。

这些是属性模型的理论值。实际挖掘速度取决于工具和方块，幸运只影响使用玩家 Luck 属性的掉落表；实际跳跃高度与起跳速度不是线性关系。

## 客户端与服务端

- 六项原版属性修正会同时在服务端和本地客户端应用，固定修正 ID 防止重复叠加。
- 跳跃高度在客户端预测和服务器端跳跃事件中同时调整。
- 防御力在服务端的最终伤害阶段应用额外减伤。
- 挖掘速度同时使用 BLOCK_BREAK_SPEED 和 MINING_EFFICIENCY。
- 服务器存档仍是属性分配的权威数据来源。

## 旧原型数据升级

- 力量的已分配点数保留。
- 旧原型中的敏捷、体质、智力和精神点数释放回可用属性点。
- 当前等级、历史最高等级和累计属性点公式不变。

## 建议测试

1. 同一武器、同一目标测试力量前后伤害。
2. 比较最大生命值。
3. 分别测试普通攻击、爆炸和燃烧伤害，检查防御力。
4. 使用相同工具破坏相同方块，检查挖掘速度。
5. 在明确读取 Luck 的战利品表中验证幸运；单次掉落不能判断概率变化。
6. 在相同地面条件下比较移动速度。
7. 在相同地点和状态下比较实际跳跃高度。
8. 重置、重新登录和死亡重生后，确认效果能撤销及恢复。
