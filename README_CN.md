# RPG Core Prototype 0.3.0

Minecraft Java 1.21.1 / NeoForge 21.1.265 / Java 21。

RPG Core 保留原版生存、建造、挖矿、合成与经验系统；不设置职业，也没有技能树或职业限制。

## 当前成长系统

- RPG 等级直接跟随 Minecraft 原版玩家经验等级，不再拥有独立的 RPG 经验条或升级曲线。
- 玩家通过原版方式获得经验、升级或消耗等级时，RPG 界面与等级成长效果同步变化。
- 属性点按玩家达到过的最高等级累计计算。消耗原版等级（例如进行附魔）不会追回已经获得的属性点，也不会让已分配属性点变成负数。
- 每次首次安装/升级初始化时，会把玩家当前原版等级作为同步等级；已有角色已分配的属性会保留。
- 每次达到等级 x 的属性点奖励仍为 floor(x / 2) + min(100, x)。
- 累计属性点公式：P(x) = floor(x² / 4) + x(x + 1) / 2（0 到 100 级）；P(x) = floor(x² / 4) + 100x - 4950（100 级以上）。
- 玩家可自由分配力量、敏捷、体质、智力、精神五项属性，并可免费重置。
- 玩家数据由服务器验证、按玩家独立保存，并同步给对应玩家。
- 按 P 打开属性界面，支持简体中文和英文。

## 已加入的首批实际效果（0.3.0 原型数值）

等级基础成长与属性点加成分开计算。以下为首轮测试用的临时换算值，之后可根据游戏体验调整：

- **等级基础成长**：当前 RPG 等级的平方根参与计算；每个平方根等级单位增加 0.50 最大生命和 0.05 护甲。
- **敏捷**：每个平方根敏捷点增加 0.15% 移动速度。
- **体质**：每个平方根体质点增加 0.50 最大生命和 0.08 护甲。
- 为避免属性点总量快速增长造成数值失控，单项属性参与效果计算的点数最多按 10,000 计算，并使用平方根换算。
- 等级基础成长按当前等级计算；如果玩家消耗原版等级，等级基础加成会随当前等级下降。已获得属性点仍按历史最高等级保留。
- 属性修正由服务器计算，使用独立的临时属性修正；分配、重置、等级变化、登录和重生时重新计算，不会重复叠加。
- 力量、智力与精神目前只保存和分配，暂不产生实际效果；不会加入尚未设计的技能或魔法系统。

## 构建环境

- Minecraft Java Edition 1.21.1
- NeoForge 21.1.265
- Java 21
- ModDevGradle 2.0.148
- Gradle 9.x

在项目根目录运行 BUILD_WINDOWS.bat，成功后 JAR 位于 build/libs/。也可以使用 GitHub Actions 的 Build RPG Core Prototype 工作流下载构建产物。

## 建议测试

1. 进入世界，按 P，确认 RPG 等级与原版经验等级一致。
2. 记录未分配属性时的生命、护甲和移动速度。
3. 分配敏捷，确认移动速度提高；分配体质，确认最大生命和护甲提高。
4. 免费重置属性，确认属性修正撤销且可用属性点恢复。
5. 升级和消耗原版等级，确认等级基础成长随当前等级同步；历史获得属性点不被追回。
6. 退出重进、死亡重生后，确认属性效果正确恢复且没有重复叠加。
7. 确认不同玩家的属性和效果互不影响。
