# RPG Core Prototype 0.3.0

Minecraft Java 1.21.1 / NeoForge 21.1.265 / Java 21。

RPG Core 保留原版生存、建造、挖矿、合成与经验系统；当前不设置职业、技能树或职业限制。

## 当前成长系统

- RPG 等级直接跟随 Minecraft 原版玩家经验等级，不再拥有独立的 RPG 经验条或升级曲线。
- 玩家通过原版方式获得经验、升级或消耗等级时，RPG 界面中的当前等级同步变化。
- 属性点按玩家达到过的最高等级累计计算。消耗原版等级（例如进行附魔）不会追回已经获得的属性点，也不会让已分配属性点变成负数。
- 每次首次安装/升级初始化时，会把玩家当前原版等级作为同步等级；已有角色的最高等级记录会保留。
- 每次达到等级 x 的属性点奖励仍为 floor(x / 2) + min(100, x)。
- 累计属性点公式保持不变：P(x) = floor(x² / 4) + x(x + 1) / 2（0 到 100 级）；P(x) = floor(x² / 4) + 100x - 4950（100 级以上）。
- 玩家可自由分配以下七项属性，并可免费重置：力量、生命值、防御力、挖掘速度、幸运、速度、跳跃高度。
- 玩家数据由服务器验证、按玩家独立保存，并同步给对应玩家。
- 按 P 打开属性界面，支持简体中文和英文。

## 七项属性的首轮实际效果

以下为首轮原型换算值，集中定义在 RpgGameplayEffects 中，之后可根据实际游戏体验统一调整。属性点先限制在单项 10,000 点以内，再以分配点数的平方根参与换算：

| 属性 | 对应的游戏效果 | 每个平方根属性点的原型换算 |
|---|---|---:|
| 力量 | 攻击伤害 | +0.10 攻击伤害 |
| 生命值 | 最大生命值 | +0.50 最大生命值 |
| 防御力 | 护甲值 | +0.20 护甲 |
| 挖掘速度 | 方块破坏速度 | +0.5% 方块破坏速度 |
| 幸运 | 原版幸运属性 | +0.05 幸运 |
| 速度 | 移动速度 | +0.15% 移动速度 |
| 跳跃高度 | 玩家起跳时的向上速度 | +0.2% 起跳向上速度 |

- 当前 RPG 等级本身不额外增加生命或护甲；等级只影响当前等级显示及历史最高等级对应的属性点累计。
- 跳跃高度通过玩家跳跃事件调整玩家自己的起跳速度，不使用只作用于马匹的跳跃属性。
- 分配、重置、等级变化、登录和重生时会重新计算服务器端属性修正；修正使用稳定的临时修正 ID，不会因反复计算而重复叠加。
- 降低最大生命值时，会把当前生命值限制在新的最大生命值以内。
- 上述换算是原型测试值，并非最终平衡承诺。

## 旧原型数据升级说明

- 力量的已分配点数会继续保留。
- 旧原型中的敏捷、体质、智力和精神不属于现在确定的属性；这些旧属性的已分配点数会释放回可用属性点，方便重新分配到七项正式属性。
- 当前等级、历史最高等级和按原公式累计获得的总属性点不会因为这次属性调整而改变。

## 构建环境

- Minecraft Java Edition 1.21.1
- NeoForge 21.1.265
- Java 21
- ModDevGradle 2.0.148
- Gradle 9.x

在项目根目录运行 BUILD_WINDOWS.bat，成功后 JAR 位于 build/libs/。也可以使用 GitHub Actions 的 Build RPG Core Prototype 工作流下载构建产物。

## 建议测试

1. 进入世界，按 P，确认 RPG 等级与原版经验等级一致，界面恰好显示七项属性。
2. 分配力量，确认攻击伤害提高。
3. 分配生命值和防御力，确认最大生命值和护甲提高。
4. 分配挖掘速度和幸运，确认对应原版属性效果变化。
5. 分配速度和跳跃高度，确认移动速度和玩家实际跳跃高度变化。
6. 免费重置属性，确认所有七项属性效果撤销且可用属性点恢复。
7. 升级和消耗原版等级，确认历史获得属性点不被追回。
8. 退出重进、死亡重生后，确认属性效果正确恢复且没有重复叠加。
9. 确认不同玩家的属性和效果互不影响。
