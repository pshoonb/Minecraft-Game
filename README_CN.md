# RPG Core Prototype 0.3.0

Minecraft Java 1.21.1 / NeoForge 21.1.265 / Java 21。

RPG Core 保留原版生存、建造、挖矿、合成与经验系统；当前不设置职业、技能树或职业限制。

## 当前成长系统

- RPG 等级直接跟随 Minecraft 原版玩家经验等级，不再拥有独立的 RPG 经验条或升级曲线。
- 玩家通过原版方式获得经验、升级或消耗等级时，RPG 界面中的当前等级同步变化。
- 属性点按玩家达到过的最高等级累计计算。消耗原版等级（例如进行附魔）不会追回已经获得的属性点，也不会让已分配属性点变成负数。
- 每次首次安装/升级初始化时，会把玩家当前原版等级作为同步等级；已有角色的最高等级记录会保留。
- 每次达到等级 x 的属性点奖励仍为 floor(x / 2) + min(100, x)。
- 累计属性点公式保持不变：P(x) = floor(x² / 4) + x(x + 1) / 2（0 到 100 级）；P(x) = floor(x² / 4) + 100x - 4950（100 级以上）。
- 玩家可自由分配以下七项属性，并可免费重置：力量、生命值、防御力、挖掘速度、幸运、速度、跳跃高度。
- 玩家数据由服务器验证、按玩家独立保存，并同步给对应玩家。
- 按 P 打开属性界面，支持简体中文和英文。

## 七项属性的新版成长曲线

属性效果不再对投入点数设置 10,000 点硬上限。现在使用真正的软上限：

[
E(p)=
\begin{cases}
p,&p\le25\\
25+15\ln(1+(p-25)/15),&p>25
\end{cases}
]

前 25 点按完整比例生效；超过 25 点后，后续投入仍然持续增加效果，但边际收益逐渐降低，不会在某个点数停止成长。

## 七项属性的新版实际效果

| 属性 | 游戏效果 | 每个有效属性点 |
|---|---|---:|
| 力量 | 攻击伤害 | +0.75 |
| 生命值 | 最大生命值 | +1.0 |
| 防御力 | 护甲值 | +0.60（护甲加成最多 +30） |
| 挖掘速度 | 方块破坏速度 | +5% |
| 挖掘速度 | 合适工具的额外挖掘效率 | +0.75 |
| 幸运 | 原版幸运属性 | +0.50 |
| 速度 | 移动速度 | +3% |
| 跳跃高度 | 玩家起跳向上速度 | +2.5% |

防御力另外提供三种实际保护：
- 对最终受到的各种伤害额外减伤，最高逐渐趋近 65%，包含绕过原版护甲的伤害类型。
- 缩短燃烧持续时间，最高逐渐趋近 60%。
- 降低爆炸击退，最高逐渐趋近 70%。

示例（仅计算单项属性）：
- 投入 10 点时，力量增加 7.5 攻击伤害；生命值增加 10 最大生命；挖掘速度增加 50% 方块破坏速度并增加 7.5 合适工具挖掘效率；幸运增加 5；速度增加 30%；跳跃起跳速度增加 25%。
- 投入 10 点防御力时，额外减少约 16.3% 最终伤害、增加 6 护甲，并缩短燃烧时间和爆炸击退。
- 1000 级累计可获得 345,050 点。若全部投入同一属性，软上限换算约为 176 个有效属性点；效果仍会继续增长，不会因为达到 10,000 点而停止。

技术实现说明：
- 力量、生命值、防御力、挖掘速度、幸运和速度的属性修正会在服务器和本地客户端同时应用，并使用固定修正 ID 防止重复叠加。
- 挖掘速度同时使用 BLOCK_BREAK_SPEED（整体方块破坏速度倍率）和 MINING_EFFICIENCY（使用合适工具时额外增加的挖掘效率）。
- 幸运增加原版 LUCK 属性；只有读取玩家幸运值的战利品表/掉落机制才会受其影响，并非所有掉落表都会改变。
- 跳跃高度在客户端本地预测和服务器端实际玩家跳跃事件中同时调整起跳速度。
- 防御力在原版护甲和附魔减伤处理后再次减少最终伤害，因此可以覆盖原版护甲属性无法处理的伤害类型，例如绕过护甲的火焰伤害。
- 以上均为首轮玩法数值，后续根据实际测试调整；不改变既定等级与属性点公式。

## 旧原型数据升级说明

- 力量的已分配点数会继续保留。
- 旧原型中的敏捷、体质、智力和精神不属于现在确定的属性；这些旧属性的已分配点数会释放回可用属性点，方便重新分配到七项正式属性。
- 当前等级、历史最高等级和按原公式累计获得的总属性点不会因为这次属性调整而改变。

## 建议测试

1. 进入世界，按 P，确认 RPG 等级与原版经验等级一致，界面恰好显示七项属性。
2. 分配力量，使用相同武器和相同攻击对象，比较伤害。
3. 分配生命值，比较最大生命值。
4. 分配防御力，分别测试普通攻击、爆炸和燃烧伤害，比较受到的生命值损失与燃烧持续时间。
5. 分配挖掘速度，使用同一工具破坏相同方块，分别测试合适工具和不合适工具的速度。
6. 分配幸运，在明确读取 Luck 属性的战利品表（例如钓鱼）中进行大量对照测试；单次掉落不能证明概率变化。
7. 分配速度，比较相同地面条件下移动固定距离所需时间。
8. 分配跳跃高度，比较同一地点、同一状态下的实际最高跳跃高度。
9. 免费重置属性，确认所有七项效果撤销且可用属性点恢复。
10. 退出重进、死亡重生后，确认属性效果正确恢复且没有重复叠加。
11. 确认不同玩家的属性和效果互不影响。
