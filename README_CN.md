# RPG Core Prototype 0.2.7

Minecraft Java 1.21.1 / NeoForge 21.1.265 / Java 21。

RPG Core 保留原版生存、建造、挖矿、合成与经验系统；当前不设置职业，也没有技能树或职业限制。

## 当前成长系统

- RPG 等级直接跟随 Minecraft 原版玩家经验等级，不再拥有独立的 RPG 经验条或升级曲线。
- 玩家通过原版方式获得经验、升级或消耗等级时，RPG 界面中的玩家等级会同步变化。
- 属性点按玩家达到过的最高等级累计计算。消耗原版等级（例如进行附魔）不会追回已经获得的属性点，也不会让已分配属性点变成负数。
- 每次首次安装/升级初始化时，会把玩家当前原版等级作为同步等级。
- 每次达到等级 x 的属性点奖励仍为 floor(x / 2) + min(100, x)。
- 累计属性点公式：P(x) = floor(x² / 4) + x(x + 1) / 2（0 到 100 级）；P(x) = floor(x² / 4) + 100x - 4950（100 级以上）。
- 玩家可自由分配八项属性并可免费重置：力量、防御力、生命值、挖掘速度、速度、跳跃高度、幸运、经验掠夺。
- 属性面板分别显示八项属性的已分配点数与效果说明。经验掠夺显示参与经验计算的倍率加成（每点 2%，暂定）；其余七项显示预期影响，并明确标记换算规则尚未接入。
- 经验掠夺只作用于玩家对实体造成过实际伤害、且最后一次伤害未超过 60 秒的实体经验掉落；每次有效攻击都会刷新计时。
- 实体死亡时，系统快照有效参与者的经验掠夺属性并取最高值，不要求参与者在击杀时在线：
  - 仍在线的参与者读取击杀时的当前属性。
  - 已离线的参与者使用其登出事件中记录的最新属性值。
  - 玩家下线不会清除参与记录；只有超过 60 秒未再次造成伤害才会失去资格。
- 每次实体经验掉落事件单独结算。设该批原版总经验为 S、按原版面额拆分得到的逻辑经验球数为 N、死亡时最高经验掠夺点数为 L：
  - P = floor(S × (1 + 2% × L))
  - Q = P // (max(2, N) - 1)
  - 本批 N 颗逻辑经验球全部使用新面额 Q。
- 系统取消该批原版经验球生成，再只生成本批自己的新经验球；不会扫描或修改周围已经存在的经验球，也不会影响其他实体或挖矿、熔炼等非实体经验来源。
- 原版经验球后续可能把相同面额的球合并为一个带数量的经验球实体；合并只累计球的数量，不改变每颗球的面额。不同面额的经验球不会被本系统改写。
- 末影龙等分批发放经验的实体会逐批处理，保留原版逐批掉落时机；每一批都使用该实体死亡时记录的属性快照。
- 为保证世界保存/重新载入后面额仍为正数，单颗经验球的自定义面额上限为 32767。达到上限时会截断单球面额。
- 玩家数据由服务器验证、按玩家独立保存，并同步给对应玩家。
- 打开玩家背包（Inventory）后，点击背包下方的「RPG 属性面板」按钮打开属性界面；支持简体中文和英文。

## 当前尚未完成

- 力量、防御力、生命值、挖掘速度、速度、跳跃高度、幸运目前记录与分配，但尚未连接到 Minecraft 实际属性或事件；具体换算比例尚未定案。
- 经验掠夺首版暂定每点增加 2% 经验计算倍率，属性面板会按当前点数动态显示该倍率；该数值属于可调整的平衡参数，后续测试后再定稿。
- 探索、任务、采集专属奖励，怪物等级、装备、掉落与任务系统尚未实现。
- 本版本调整了尚未有玩家使用的属性数据结构；旧的敏捷、体质、智力、精神字段不再保留。

## 构建环境

- Minecraft Java Edition 1.21.1
- NeoForge 21.1.265
- Java 21
- ModDevGradle 2.0.148
- Gradle 9.x

在项目根目录运行 BUILD_WINDOWS.bat，成功后 JAR 位于 build/libs/。建议先在独立测试实例和临时世界中验证。

## 建议测试

1. 确认属性面板只显示八项属性，顺序为力量、防御力、生命值、挖掘速度、速度、跳跃高度、幸运、经验掠夺。
2. 确认八项属性均可分配、重置，点数合计不超过可用属性点。
3. 确认各项属性点在退出重进后正常保存。
4. 确认经验掠夺百分比随属性点动态变化，并与服务器端经验计算使用相同常量。
5. 确认其余七项明确显示预期效果和“换算规则尚未接入”，不显示未经批准的数值。
6. 在多人环境中确认各玩家属性互不影响。
7. 多名玩家攻击同一实体，确认只使用有效参与者中最高的经验掠夺属性。
8. 玩家最后一次造成伤害满 60 秒后，确认其不再参与该实体的经验结算。
9. 用玩家近战与玩家发射的投射物攻击实体，确认参与者都能正确记录。
10. 用原始总经验 6（3+3，N=2）、10（7+3，N=2）、960（617+307+17+17+1+1，N=6）等测试数据验证原版拆分球数 N，以及 P 和 Q 的向下取整结果。
11. 确认每批只生成 N 颗逻辑经验球，所有新球面额均为 Q，且原版掉落没有重复生成。
12. 让本次生成的球靠近原本存在的同面额经验球，确认合并只增加数量，不改变面额；不同面额的已有球保持不变。
13. 测试末影龙多个经验掉落批次，确认各批都生效且仍按原版时间逐批掉落。
14. 测试 Q 超过 32767 的极端属性/掉落情况，保存并重新载入世界，确认经验球面额仍为正数。
15. 确认原本不掉经验的实体不会凭空产生经验，挖矿、熔炼等非实体经验不受影响。
16. 在不同 GUI 缩放/分辨率下确认八项属性与分配按钮均可见、可操作。
