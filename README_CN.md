# RPG Core Prototype 0.2.1

Minecraft Java 1.21.1 / NeoForge 21.1.265 / Java 21。

RPG Core 保留原版生存、建造、挖矿、合成与经验系统；当前不设置职业，也没有技能树或职业限制。

## 当前成长系统

- RPG 等级直接跟随 Minecraft 原版玩家经验等级，不再拥有独立的 RPG 经验条或升级曲线。
- 玩家通过原版方式获得经验、升级或消耗等级时，RPG 界面中的玩家等级会同步变化。
- 属性点按玩家达到过的最高等级累计计算。消耗原版等级（例如进行附魔）不会追回已经获得的属性点，也不会让已分配属性点变成负数。
- 每次首次安装/升级初始化时，会把玩家当前原版等级作为同步等级；已有角色已分配的属性会保留。
- 每次达到等级 x 的属性点奖励仍为 floor(x / 2) + min(100, x)。
- 累计属性点公式：P(x) = floor(x² / 4) + x(x + 1) / 2（0 到 100 级）；P(x) = floor(x² / 4) + 100x - 4950（100 级以上）。
- 玩家可自由分配力量、敏捷、体质、智力、精神五项属性，并可免费重置。
- 玩家数据由服务器验证、按玩家独立保存，并同步给对应玩家。
- 按 P 打开属性界面，支持简体中文和英文。

## 当前尚未完成

- 属性点目前只记录与分配，尚未转换成生命、攻击、防御、移动等实际游戏数值。具体换算比例尚未定案。
- 探索、任务、采集专属奖励，怪物等级、装备、掉落与任务系统尚未实现。
- 本次改动移除了旧测试计数器及独立 RPG 经验逻辑。

## 构建环境

- Minecraft Java Edition 1.21.1
- NeoForge 21.1.265
- Java 21
- ModDevGradle 2.0.148
- Gradle 9.x

在项目根目录运行 BUILD_WINDOWS.bat，成功后 JAR 位于 build/libs/。建议先在独立测试实例和临时世界中验证。

## 建议测试

1. 进入世界，按 P，确认 RPG 等级与原版经验等级一致。
2. 拾取经验球，确认原版经验条正常增长，等级变化后 RPG 界面同步。
3. 使用原版方式消耗等级，确认 RPG 显示等级同步下降，但已获得属性点不会被收回。
4. 升级到新等级，确认属性点按既定公式增加。
5. 分配与免费重置属性，确认退出重进后数据仍保留。
6. 确认界面中不再出现测试计数器。
7. 在多人环境中确认各玩家属性互不影响。

当前属性点仍未影响生命、攻击、防御或移动数值。
