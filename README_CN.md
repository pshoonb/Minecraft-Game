# RPG Core Prototype 0.1.0

这是 Minecraft Java 1.21.1 / NeoForge 21.1.265 的**最小开发原型源码**。它用于先验证玩家数据持久化、死亡后保留、服务器权威写入和玩家间数据隔离。

> **重要：本次交付是源码项目 ZIP，不是可直接放进 `mods` 文件夹的已编译 JAR。** 当前制作环境无法解析外部 Maven/Gradle 下载主机，因此无法在这里完成 Gradle 依赖下载、编译或启动 Minecraft。项目代码已整理，但必须在可联网的 Windows / Linux / macOS 电脑上构建并运行测试后，才能确认原型可用。

## 1. 本原型做了什么

- NeoForge 1.21.1 模组入口和客户端/专用服务器分离注册。
- 使用持久化 Entity Data Attachment 存放每位玩家自己的数据。
- 通过 Codec 保存七项 RPG 属性字段、历史等级/奖励字段、重置基准等级和诊断计数器。
- 设置 `copyOnDeath()`，用于验证死亡重生后数据继续保留。
- 自定义网络消息：客户端只请求读取或请求增加诊断计数器；真正的数值由服务器读取、修改和保存。
- 服务器只把对应玩家的数据快照发回该玩家；请求包中不包含可指定其他玩家 UUID 的目标参数。
- 按 `P` 打开英文诊断窗口；点击 `Increment Test Counter` 后，服务器将该玩家的计数器加一并同步回来。
- 离开服务器/世界时清理客户端缓存，避免切换服务器后短暂显示上一个世界的数据。

诊断计数器只是**持久化与同步测试按钮**，不是正式属性点，不会影响战斗或角色成长。

## 2. 目前没有实现什么

此原型还没有正式启用：七项属性效果、属性点分配/取回、升级奖励公式、软上限、Defense 减伤、Attack 加伤、速度/跳跃/挖掘效果、Luck 掉落、右侧 HUD、正式 RPG 美术菜单、完整角色重置和装备加成。

这些将在存档和多人隔离测试通过后逐项加入。不要将本原型当作完整 RPG 模组使用，也不要直接放到重要的正式服务器或已有主世界中测试。

## 3. 固定开发目标

- Minecraft Java Edition 1.21.1
- NeoForge 21.1.265
- 64 位 Java 21 JDK
- ModDevGradle 2.0.148
- Gradle 9.2.1（构建脚本会按需下载）
- 不依赖其他第三方运行时模组库

客户端与服务器使用同一个 RPG Core JAR。多人游戏时，服务器和每位玩家客户端都必须安装相同 Minecraft、NeoForge 和本模组版本。

## 4. Windows 构建步骤（推荐）

1. 安装 **64 位 Java 21 JDK**。安装后打开命令提示符，输入 `java -version`，确认显示版本 21。
2. 将整个 `RpgCorePrototype` 文件夹解压到一个容易找到的位置。不要只复制 `src` 文件夹。
3. 确保电脑可以访问互联网。首次构建需要下载 Gradle、NeoForge 和 Minecraft 开发依赖，下载量较大。
4. 双击 `BUILD_WINDOWS.bat`。如果 Windows 弹出网络或安全确认，请确认你是在自己信任的项目文件夹中运行该脚本。
5. 等待构建完成。成功时，JAR 应位于：

   `build\\libs\\rpgcore-0.1.0-prototype.jar`

6. 如果构建失败，保留命令窗口中的完整错误文字或截图。不要猜测性地修改 Java 源码；可以把错误信息发回来继续排查。

## 5. 安装并运行这个原型

只有在上一步成功生成 JAR 后才进行：

1. 为 Minecraft Java 1.21.1 安装 NeoForge 21.1.265。
2. 首次启动该 NeoForge 配置，让 Minecraft 创建游戏目录，然后退出游戏。
3. 找到该游戏目录中的 `mods` 文件夹。若没有，就新建一个名为 `mods` 的文件夹。
4. 把 `rpgcore-0.1.0-prototype.jar` 放入 `mods` 文件夹。
5. 用 NeoForge 1.21.1 配置启动 Minecraft，创建一个新的临时测试世界。
6. 进入世界后按 `P`。应看到英文标题 `RPG DATA PROTOTYPE`。
7. 点击 `Increment Test Counter`，应看到 `Persistence Test Counter` 增加。关闭窗口再按 `P`，计数应保持。

按键可以在 Minecraft 的 **Options → Controls → Key Binds → RPG Core** 中重新绑定。

## 6. 多人服务器隔离测试

1. 在专用测试服务器上安装 NeoForge 1.21.1 和同一个 RPG Core JAR。
2. 每位加入服务器的玩家客户端也安装相同 NeoForge 版本和同一个 JAR。
3. 让两名玩家同时进入测试服务器，分别按 `P`，记下各自 UUID 和计数器。
4. 让玩家 A 点击一次或多次按钮；玩家 B 的计数器不应改变。
5. 让玩家 B 点击按钮；玩家 A 的计数器不应改变。
6. 分别退出重进，然后重启测试服务器，再检查计数器是否保留。
7. 分别死亡重生，确认计数器是否保留。

服务器数据保存于各玩家自己的实体存档数据中。不要把原型测试放在重要世界里；测试前请备份世界。

## 7. 从源码启动开发环境（可选）

如果已安装 IntelliJ IDEA，可通过 **Open** 打开整个项目文件夹，并等待 Gradle 导入完成。此后可运行 Gradle 任务：

- `runClient`：启动开发客户端。
- `runServer`：启动开发专用服务器。
- `build`：编译 JAR。

第一次运行 `runServer` 时，需要在生成的开发服务器目录中阅读并接受 Minecraft EULA；开发测试的认证配置也应仅限本机或私人测试网络使用。
