# RPG Core Prototype 0.2.0

Minecraft Java 1.21.1 / NeoForge 21.1.265 / Java 21。

这是 RPG Core 的基础成长系统原型。项目保留 Minecraft 原版生存、建造、挖矿与合成玩法；当前不设置职业，也没有加入技能树或职业限制。

> 当前交付仍是源码分支与 Draft Pull Request，不代表已经成功编译或通过游戏内测试。请先使用独立测试实例，不要直接用于重要存档或正式服务器。

## 当前实现

- 每位玩家独立保存 RPG 等级、RPG 经验、五项属性和诊断计数器。
- RPG 经验与 Minecraft 原版经验分开。拾取原版经验球时，会额外获得同数值的 RPG 经验；原版经验球不会被取消或扣减，因此附魔经验系统不受影响。
- 默认经验需求：0 级升 1 级需要 100 RPG 经验；之后每升一级，下一等级需求增加 25。服务器可在 config/rpgcore-server.toml 调整。
- RPG 等级上限暂定 100,000，避免无界等级导致数值溢出。
- 每次升到等级 x，获得 floor(x / 2) + min(100, x) 属性点。
- 累计属性点通项公式：P(x) = floor(x² / 4) + x(x + 1) / 2（0 到 100 级）；P(x) = floor(x² / 4) + 100x - 4950（100 级以上）。
- 首次加入时，将玩家当时的原版经验等级作为 RPG 初始等级基准；之后 RPG 等级独立成长。已有世界的老玩家可按已有等级获得累计属性点。
- 玩家可自由分配力量、敏捷、体质、智力、精神五项属性。
- 可免费重置属性分配。
- 分配、重置和经验发放均由服务器验证并写入；客户端不能指定其他玩家的数据。
- 玩家数据使用 NeoForge Attachment 持久化，网络同步按玩家 UUID 校验。
- P 键打开成长界面，支持简体中文和英文界面。

## 当前尚未完成

- 属性点目前只记录与分配，尚未转换成生命、攻击、防御、移动等实际游戏数值。具体换算比例尚未定案，避免擅自设定影响平衡的数值。
- 目前 RPG 经验来源是原版经验球拾取；探索奖励、任务奖励、独立采集奖励和特殊挑战奖励尚未实现。
- 怪物等级、装备、掉落、任务与探索系统尚未实现。
- 诊断计数器暂时保留，用于继续验证玩家数据存档和同步。
- 尚未完成 Gradle/NeoForge 编译、客户端启动、多人测试和完整存档重启测试。

## 构建环境

- Minecraft Java Edition 1.21.1
- NeoForge 21.1.265
- Java 21
- ModDevGradle 2.0.148
- Gradle 9.x

Windows 可在项目根目录运行 BUILD_WINDOWS.bat。成功后 JAR 预期位于 build/libs/。也可以在 IntelliJ IDEA 中打开项目，等待 Gradle 导入后运行 build 或 runClient。

首次构建需要网络下载 Gradle、Minecraft 和 NeoForge 开发依赖。构建成功后，先把 JAR 放入独立测试实例的 mods 文件夹。

## 测试建议

1. 使用新的临时世界测试，不要直接在重要世界验证。
2. 按 P 打开菜单，确认 RPG 等级和五项属性显示正常。
3. 拾取经验球，确认 RPG 经验增加，同时原版经验照常增加。
4. 达到升级所需经验后，确认等级与可用属性点增加。
5. 分配属性、免费重置，关闭界面再打开，确认数据同步。
6. 退出重进并重启测试世界，检查 Attachment 是否持久化。
7. 多人测试时确认玩家之间的数据互不影响。

所有经验需求默认值和属性效果都应在测试后继续平衡。当前版本不会改变原版生命、攻击或防御数值。
