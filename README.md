# Minecraft RPG Core Prototype 0.3.0

Minecraft Java Edition 1.21.1 / NeoForge 21.1.265 prototype.

RPG Core preserves vanilla survival, building, mining, crafting, and experience. It currently has no class system, skill tree, or class restrictions.

The attribute screen has exactly seven assignable attributes: Strength, Health, Defense, Mining Speed, Luck, Speed, and Jump Height. See README_CN.md for the progression formula, prototype effect tuning, and legacy-data migration details. See TEST_PLAN.md for the validation checklist.

The GitHub Actions workflow builds with Java 21 and Gradle 9.x.
