# Minecraft RPG Core Prototype

Minecraft Java Edition 1.21.1 / NeoForge 21.1.265 prototype.

The eight intended RPG attributes are Strength, Defense, Health, Mining Speed, Movement Speed, Jump Height, Luck and Experience Loot.

See `README_CN.md` for project notes and `TEST_PLAN.md` for the validation checklist. The GitHub Actions workflow builds with Java 21 and Gradle 9.2.1.
